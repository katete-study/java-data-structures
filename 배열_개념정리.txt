C 자료구조 개념 정리
====================================

[배열 (Array)]
- 객체 : <인덱스, 값> 쌍의 집합
- 연산 : 
    - create(size) : size개의 요소를 지정할 수 있는 배열 생성
    - get(A,i) : 배열 A의 i번째 요소 반환 (만약 인덱스가 유효하지 않다면, 오류를 반환한다.)
    - set(A,i,v) : 배열 A의 i번째 위치에 값 v 저장함.
- 컴파일러 : 
    - C 언어 : 지역 변수로 int arr[5]; 선언 시 스택 영역에서 4바이트 5개가 연속 할당됨
              포인터 연산으로 메모리 주소에 직접 접근 가능. 인덱스 범위 벗어나도 컴파일러 막지 않아서 위험
              연속된 메모리에 들어가는 것은 "실제 값임"
    
    - java/kotlin : 배열 자체는 무조건 힙에 저장되는 객체임.
                    스택 영역의 변수는 힙 영역에 생성된 배열 객체의 참조 주소만 가지고 있음.
                    JVM이 런타임에 배열 길이를 관리함. 범위를 벗어나면 ArrayIndexOutOfBoundsException을 던져 안전하게 방어.
                    int [] arr = new int[5];를 생성하면 JVM 힙 메모리에는 먼저 JVM이 객체를 식별하기 위한 메타데이터(GC 정보, 락 정보, 클래스 정보)와 배열의 길이가 먼저 할당됨.
                    헤더 뒤에 C 언어와 같이 연속된 공간에 원소들이 순차적으로 채워짐.

[구조체 (Struct)]
- 배열이 타입이 같은 데이터 모임은 구조체는 탑이 다른 데이터를 묶는 방식이다.
    - C 언어 : Struct 구조체 이름 { 항목1;, 항목2; ...}
