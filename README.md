# java-data-structures

Java 자료구조 + 코딩테스트 대비 스터디 레포입니다.

## 🎯 목표
- 프로그래머스 **PCCP(Java) 2026.10.18** 응시 + 대기업 코테 합격 수준
- 기존 언어는 Kotlin 위주 → Java 문법은 처음부터 함께 정리
- 자료구조는 직접 구현이 아니라 `java.util` 사용법 + 동작 원리 이해 중심
- 매일 **개념 정리 → 예제 코드 → 코테 문제 풀이**
